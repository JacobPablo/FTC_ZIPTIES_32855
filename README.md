This is the official website for **FTC Zipties Team #32855**, showcasing our FIRST Tech Challenge team, robot engineering, and team sponsors in a compact yet thorough format.

**Features**
Key features are:
	High Interactivity: The website utilises interactive features to ensure a user-friendly experience for users
	Responsive UI & Theme Toggle: The website UI has been made extremely responsive to ensure fast navigation; the theme toggle also allows users to read the website at their comfort level.
	GitHub Pages: The website is published and run using GitHub Pages, making it easily accessible.

**Code**
The programming languages used for the website's development are:
  **HTML5**: It defines what is on the page (headings, paragraphs, images, buttons, and links).
  **CSS3**:  Defines the website's styling, such as colours, fonts, text size, etc.
  **JavaScript (v20.14.0)**: Handles the website's functionality and interactivity (Light/Dark Mode, Sponsorcards, etc)

To visit the website, you can either:
  **Visit the Website by copy-pasting this link in your browser: https://jacobpablo.github.io/FTC_ZIPTIES_32855/**
	Or
  1. Go to the main repository page and click the Fork button near the top-right corner.
  2. Navigate to your newly created fork, then click on Settings (top navigation tab of your fork).
  3. In the left sidebar, click Pages. Under Build and deployment > Source, select Deploy from a branch.
  4. Under Branch, pick main (or master), select / (root), and click Save.
  5. The site will be available at https://jacobpablo.github.io/FTC_ZIPTIES_32855/
